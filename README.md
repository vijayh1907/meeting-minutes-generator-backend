# CrewAi LLM

# 📝 Meeting Transcript Classifier (CrewAI)

This project uses [CrewAI](https://github.com/joaomdmoura/crewai) to automatically classify meeting transcript lines into **Action, Question, or Discussion**, with tags, confidence scores, and explanatory notes.

It demonstrates a modular CrewAI setup with **Agent**, **Tool**, and **Task** separated into clean modules, orchestrated by `crew.py`.

---

## 📂 Project Structure

```
.
├── crewAgent1.py                           # Orchestrator (entry point)
├── call_transcript.txt                     # Example transcript file
├── src/
│   ├── agents/
│   │   └── meeting_classifier_agent.py    # Meeting classifier Agent
│   ├── tasks/
│   │   └── classify_task.py               # Batch classification Task
│   ├── tools/
│   │   └── transcript_reader_tool.py      # TranscriptReaderTool (txt/pdf/docx)
│   └── io_utils.py                        # Helpers for saving JSON/CSV
```

## ⚙️ Installation

1. Clone this repo and `cd` into it.
2. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate    # on Linux/Mac
   venv\Scripts\activate     # on Windows
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   **Key dependencies:**
   - `crewai`
   - `langchain-openai`
   - `python-docx`
   - `pypdf`
   - `pandas`
   - `python-dotenv`

4. Create a `.env` file with your OpenAI API key:
   ```env
   OPENAI_API_KEY=sk-...
   ```

## 🚀 Usage

Run classification on a transcript:

```bash
python crew.py --input call_transcript.txt --out outputs
```

Arguments:
- `--input` → path to transcript (`.txt`, `.docx`, `.pdf`)
- `--out` → output directory (default: `outputs/`)
- `--model` → model name (default: `openai/gpt-4o-mini`)
- `--temperature` → LLM temperature (default: `0.1`)

## 📦 Components

### 🔹 Agent
- Role: *Meeting Snippet Classifier*
- Goal: Label transcript lines with:
  - `raw_transcript_line`
  - `category` (Action | Question | Discussion)
  - `tags[]`
  - `confidence` (0–1)
  - `notes`

### 🔹 Tool
- Reads `.txt`, `.docx`, `.pdf` transcripts.
- Cleans timestamps/bullets.
- Returns structured list:  
  ```json
  [{"id": "seg_0001", "text": "Good morning everyone, let's get started."}, ...]
  ```

### 🔹 Task
- Batch task that instructs the agent to:
  - Use `TranscriptReaderTool`
  - Classify each transcript line
  - Return a **single JSON array** of objects

### 🔹 Utilities
- `save_json()` → writes results as `.json`
- `save_csv()` → writes results as `.csv`
